# CROOS_OPT Mini App — локальная демоверсия

`npm install`, затем `npm run dev`. Откройте адрес Vite в браузере. `npm run build` проверяет сборку.

Название меняется в `src/config.js`. Сейчас в каталоге 29 товаров и 91 фотография из профиля `O_mSgGGLqUdA7MbbfOKbdro`. Парсер нашёл 31 объявление; два объявления вернули 403 и остались пропущенными. Каталог сохраняется в IndexedDB. При первом сохранении существующие товары переносятся из localStorage. Новые фотографии автоматически сжимаются при выборе. Изменения администратора, корзина и заказы видны только на текущем устройстве.

Для двух пропущенных объявлений используйте предоставленный отдельно `kufar-parser` в ручном режиме, если Kufar позволит открыть карточки, затем `npm run import:kufar -- <путь-к-products.json>`. Импорт сохраняет несколько фотографий, устраняет дубликаты по URL и оставляет отсутствующие цену, размеры и остаток незаполненными. Обновлённый исходный каталог можно проверить в новом профиле браузера.

Панель продавца открывается из профиля Mini App. Прямая ссылка с `?view=admin` также требует успешной проверки доступа. Сервер проверяет подпись Telegram и разрешает вход аккаунтам `@ttfight27`, `@miltorzz` и `@vlagm`. Если продавец меняет username, обновите список доступа.
## Автопубликация в Telegram

В форме нового товара доступен предпросмотр поста. После сохранения бот отправляет до десяти фотографий, название, размеры, условия доставки, контакты и цену. Товар без фотографии публикуется текстом. Редактирование уже сохранённого товара не запускает публикацию. Статус отправки виден в списке товаров.

Отправка выключена по умолчанию. Для подключения добавьте `@croosopt_bot` в нужный канал с правом публикации и задайте серверные переменные Vercel:

- `TELEGRAM_BOT_TOKEN` — токен бота, только на сервере.
- `TELEGRAM_CHANNEL_ID` — числовой ID канала вида `-100…`.
- `TELEGRAM_PUBLISH_ENABLED` — `true` для включения отправки.

После обновления переменных пересоберите приложение и откройте Mini App из бота. Сервер проверяет подпись и возраст данных Telegram и применяет тот же список доступа, что и для панели продавца. При неопределённом результате проверьте канал: автоматического повтора нет, чтобы не продублировать пост.

Каталог демоверсии хранится на устройстве. Добавление товара на одном устройстве не обновит каталог подписчиков без общего хранилища.

## Заказы в закрытой группе Telegram

Добавьте `@croosopt_bot` в закрытую группу с правом отправлять сообщения и задайте на сервере `TELEGRAM_ORDERS_CHAT_ID` равным её числовому ID. Сервер проверяет подпись данных покупателя из Mini App и передаёт заказ в группу с его Telegram-ником, телефоном и данными доставки. Если ник не задан, в уведомлении будет числовой ID Telegram. После подтверждения доставки сообщения покупатель увидит номер заказа. Без настройки группы сохраняется локальный деморежим.
