# CROOS_OPT Mini App — локальная демоверсия

`npm install`, затем `npm run dev`. Откройте адрес Vite в браузере. `npm run build` проверяет сборку.

Название меняется в `src/config.js`. Сейчас в каталоге 29 товаров и 91 фотография из профиля `O_mSgGGLqUdA7MbbfOKbdro`. Парсер нашёл 31 объявление; два объявления вернули 403 и остались пропущенными. Каталог сохраняется в IndexedDB. При первом сохранении существующие товары переносятся из localStorage. Новые фотографии автоматически сжимаются при выборе. Изменения администратора, корзина и заказы видны только на текущем устройстве.

Для двух пропущенных объявлений используйте предоставленный отдельно `kufar-parser` в ручном режиме, если Kufar позволит открыть карточки, затем `npm run import:kufar -- <путь-к-products.json>`. Импорт сохраняет несколько фотографий, устраняет дубликаты по URL и оставляет отсутствующие цену, размеры и остаток незаполненными. Обновлённый исходный каталог можно проверить в новом профиле браузера.

После размещения на HTTPS укажите URL в настройках меню бота через BotFather. Один бот может дать кнопку магазина и отдельную кнопку с адресом `?view=admin`. Демо-переключатель роли не защищает данные. Для реального доступа нужна серверная проверка `initData` Telegram, роли по Telegram ID, база данных и серверная обработка заказов.
## Автопубликация в Telegram

В форме нового товара доступен предпросмотр поста. После сохранения бот отправляет первую фотографию, название, цену, размеры и описание. Товар без фотографии публикуется текстом. Редактирование уже сохранённого товара не запускает публикацию. Статус отправки виден в списке товаров.

Отправка выключена по умолчанию. Для подключения добавьте `@croosopt_bot` в нужный канал с правом публикации и задайте серверные переменные Vercel:

- `TELEGRAM_BOT_TOKEN` — токен бота, только на сервере.
- `TELEGRAM_CHANNEL_ID` — числовой ID канала вида `-100…`.
- `TELEGRAM_PUBLISH_ENABLED` — `true` для включения отправки.

После обновления переменных нужно пересобрать приложение и открыть Mini App из бота. Сервер проверяет подпись и возраст данных Telegram и право аккаунта публиковать в канале. Публиковать могут владелец канала и его администраторы с соответствующим правом. При неопределённом результате проверьте канал: автоматического повтора нет, чтобы не продублировать пост.

Каталог демоверсии хранится на устройстве. Кнопка поста открывает магазин, но добавление товара на одном устройстве не обновит каталог подписчиков без общего хранилища.
