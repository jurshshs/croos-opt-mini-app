# CROOS_OPT Mini App — локальная демоверсия

`npm install`, затем `npm run dev`. Откройте адрес Vite в браузере. `npm run build` проверяет сборку.

Название меняется в `src/config.js`. Сейчас в каталоге 29 товаров и 91 фотография из профиля `O_mSgGGLqUdA7MbbfOKbdro`. Парсер нашёл 31 объявление; два объявления вернули 403 и остались пропущенными. Слой данных в `src/data.js` использует JSON и localStorage. Изменения администратора, корзина и заказы видны только на текущем устройстве.

Для двух пропущенных объявлений используйте предоставленный отдельно `kufar-parser` в ручном режиме, если Kufar позволит открыть карточки, затем `npm run import:kufar -- <путь-к-products.json>`. Импорт сохраняет несколько фотографий, устраняет дубликаты по URL и оставляет отсутствующие цену, размеры и остаток незаполненными. После импорта очистите локальный ключ `croos-opt-demo-v1:products` в браузере, чтобы загрузить обновлённый каталог.

После размещения на HTTPS укажите URL в настройках меню бота через BotFather. Один бот может дать кнопку магазина и отдельную кнопку с адресом `?view=admin`. Демо-переключатель роли не защищает данные. Для реального доступа нужна серверная проверка `initData` Telegram, роли по Telegram ID, база данных и серверная обработка заказов.
